<h1 align="center">🌡️ Temperature Converter Web App</h1>

<p align="center">
  A modern and responsive temperature converter with a sleek glassmorphism UI.
</p>

<hr>

<h2>🚀 Overview</h2>
<p>
This project is a simple yet elegant <b>Temperature Converter</b> that allows users to convert values 
between <b>Celsius, Fahrenheit, and Kelvin</b> instantly. It features a clean UI and smooth user experience.
</p>

<h2>✨ Features</h2>
<ul>
  <li>🔄 Convert between Celsius, Fahrenheit, and Kelvin</li>
  <li>⚡ Instant and accurate results</li>
  <li>🎨 Modern glassmorphism design</li>
  <li>📱 Fully responsive layout</li>
  <li>🧑‍💻 Beginner-friendly project</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>HTML5</b></li>
  <li><b>CSS3</b></li>
  <li><b>JavaScript</b></li>
</ul>

<h2>🧩 How It Works</h2>
<ol>
  <li>Enter the temperature value</li>
  <li>Select the unit to convert <b>from</b></li>
  <li>Select the unit to convert <b>to</b></li>
  <li>Click <b>Convert</b> to see the result</li>
</ol>

<h2>📂 Project Structure</h2>
<pre>
temp.html      → Main UI

</pre>

<h2>🎮 Usage</h2>
<ul>
  <li>Enter temperature value</li>
  <li>Select units</li>
  <li>Click <b>Convert</b></li>
  <li>Click <b>Reset</b> to clear</li>
</ul>
